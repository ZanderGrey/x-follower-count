# X Follower Count

一个 Chrome 插件：在 X（推特）网页版浏览时间线时，**直接在头像旁显示博主的粉丝数**，不用再点进对方主页。

- 推文、回复、引用推文、关注列表 / 推荐关注里的用户都会显示
- 数字按 X 界面语言自动缩写（中文界面显示 `12.3万`，英文界面显示 `123K`），鼠标悬停可看精确值
- 按粉丝量级着色：灰色 < 1万，蓝色 1万–10万，紫色 10万–100万，粉色 ≥ 100万
- 可在插件弹窗里切换显示位置：**头像下方** 或 **@用户名后面**

## 工作原理

X 网页版在加载时间线时，返回的 JSON 里本身就带着每位作者的 `followers_count`。插件在页面里监听这些已经发生的 API 响应（`fetch` / `XMLHttpRequest`），提取出「用户名 → 粉丝数」，再把数字贴到对应头像旁边。

所以插件 **不会额外发送任何请求**，不需要登录信息或 API Key，也不会因为频繁请求触发限流。粉丝数会在本地缓存 3 天，再次看到同一个人时能立即显示。

> 局限：如果某位用户的数据从未出现在页面加载过的 API 响应里（极少见），他的头像旁就不会显示数字；滚动或刷新后通常会补上。

## 安装（开发者模式）

1. 下载或 `git clone` 本仓库
2. 打开 Chrome，访问 `chrome://extensions`
3. 打开右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本仓库的根目录
5. 打开或刷新 <https://x.com>，向下滚动即可看到粉丝数

修改代码后，在 `chrome://extensions` 里点插件卡片上的刷新按钮，再刷新 X 页面即可生效。

## 不显示怎么办

1. 在 `chrome://extensions` 里点插件卡片上的刷新按钮，然后**刷新 x.com 页面**（装好或更新插件后，已打开的页面必须刷新）
2. 在 x.com 页面上点插件图标，展开「诊断」。它会直接告诉你卡在哪一步：页面脚本没注入、没拦截到数据、还是找不到头像
3. 如果还是不行，点「复制诊断信息」，把内容贴到 issue 里

## 目录结构

```
manifest.json        Manifest V3 配置
src/page-hook.js     运行在页面环境，拦截 X 的 API 响应并提取粉丝数
src/content.js       运行在插件环境，缓存数据并在头像旁插入徽标
src/badge.css        徽标样式
popup/               插件弹窗（开关、显示位置、清空缓存）
icons/               图标
test/                端到端测试（Playwright + 模拟的 x.com 页面）
```

## 测试

```bash
npm install
npm test
```

测试会把插件加载进无头 Chromium，用模拟的 x.com 页面和 API 响应验证徽标是否出现在正确的位置、缓存是否生效。

## 打包

```bash
npm run zip   # 生成 x-follower-count.zip，可上传到 Chrome 网上应用店
```

## 注意

X 的页面结构和接口格式会不定期变化。插件依赖的关键点是头像容器的 `data-testid="UserAvatar-Container-<用户名>"` 以及 API 中用户对象的 `legacy.followers_count`；如果某天不显示了，优先检查这两处。
